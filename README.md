# 📌 Projetos em Destaque

## 🏦 Sistema Distribuído de Pagamentos com Monitoramento de Fraude
🔗 https://github.com/PeeEdu/sistema-pagamentos-monitoramento-fraude

Sistema backend baseado em microsserviços orientados a eventos para processamento bancário, transferências Pix e monitoramento antifraude.

### Tecnologias utilizadas:
- Java
- Spring Boot
- Spring WebFlux
- Spring Security
- MongoDB
- Redis
- Apache Kafka
- Camunda BPM
- JWT
- Docker & Docker Compose

### Principais conceitos aplicados:
- Microsserviços
- Event Driven Architecture
- Comunicação assíncrona com Kafka
- API Gateway
- Antifraude distribuído
- Orquestração com Camunda
- Persistência isolada por serviço
- Fluxos financeiros desacoplados
